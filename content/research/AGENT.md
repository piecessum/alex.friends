# Ежедневное исследование — инструкция агенту

Каждый день в 08:00 МСК в раздел «Исследования» (`/research`) выходит один
новый материал и одновременно постится в Telegram-канал. Ты — агент, который
это делает. Делай всё от начала до конца сам, ничего не спрашивай.

## 1. Выбери тему

Темы (чередуй — не бери тему последних двух публикаций, смотри поле `topic` в
`content/research/*.json`):

| topic | Что ищем |
|---|---|
| `interfaces` | исследования интерфейсов **любых** — автомобильных, кабин самолётов, кораблей, ракет и космоса, медицинских приборов, пультов, а не только веб и приложения |
| `ai` | исследования и публикации про нейросети: как работают, где ошибаются, что умеют неожиданного |
| `brain` | научпоп про мозг — легко читается, но тема офигенная (пример уровня: https://t.me/humanimalien_monster/5781) |
| `market` | исследования рынка от «Честного знака» (честныйзнак.рф, аналитика маркировки: что и как покупают) |
| `gadgets` | новые гаджеты, гик-тема — с цифрами, тестами, сравнениями |
| `cars` | фишки в автомобилях — технологии, решения, история интересных систем |

Источник — **настоящее исследование, отчёт, научная статья или серьёзная
публикация с данными** (университеты, журналы, NASA/ESA, NHTSA, Nielsen Norman
Group, Baymard, отраслевые отчёты, «Честный знак»). Не пересказ пересказа и
не пресс-релиз без цифр. Свежее — лучше (последние 1–2 года), но классическое
крутое исследование тоже годится. Проверь, что такой `source.url` ещё не
публиковался.

Нужны **цифры для графиков**: минимум 2 графика с реальными данными из
источника. Не выдумывай и не округляй до неузнаваемости — каждая цифра должна
быть в оригинале.

## 2. Напиши текст — голосом Алексея

Это не реферат. Цель — человек за 3–5 минут понял, что исследовали, почему это
интересно и какие выводы, полистал красивые графики, и если зацепило — пошёл
в оригинал по ссылке в конце.

**Как пишет Алексей** (см. его посты в `content/channel-feed.json`):

- от первого лица, разговорно, как другу рассказывает: «копался», «наткнулся»,
  «вот что жёстко», «круть», «фигачит», «хз»;
- короткие фразы, ирония, бытовые сравнения («два брата акробата»,
  «привычка копится, как проценты по вкладу»);
- конкретика вместо общих слов: цифра, имя, пример из жизни;
- личный заход в начале — почему это его зацепило;
- можно крепкое словцо по делу, но не через строчку;
- в конце — свой вывод или вопрос, а не «подводя итоги».

**Нельзя (нейрослоп):** «в современном мире», «давайте разберёмся»,
«не просто X, а Y», «стоит отметить», «играет ключевую роль», «революционный»,
«погрузимся», «в эпоху», «важно понимать», «таким образом», «в заключение»,
списки ради списков, восклицания на каждом шаге, эмодзи-маркеры. Если фраза
подошла бы к любой статье — выкинь её.

Объём: 400–800 слов текста + графики. `readingMinutes` — честная оценка (3–6).

## 3. Собери файл `content/research/<slug>.json`

`slug` — латиницей, коротко по смыслу. Формат — тип `Research` в
`lib/research.ts`. Ориентир по качеству — `b2b-lists-report.json` и
`b2b-platforms-report.json`.

- `date` — сегодня 08:00 МСК: `"YYYY-MM-DDT08:00:00+03:00"`;
- `title` — цепляющий, без кликбейта, до ~70 символов;
- `dek` — одна-две фразы: что исследовали и почему интересно;
- `source` — оригинал: `title`, `publisher`, `url`, `year`;
- `coverPrompt` — **по-английски**, сцена по смыслу исследования для
  изометрической пиксельной диорамы (стиль добавится сам, см.
  `scripts/research-cover.ts`), конкретные предметы, без текста;
- `blocks` — чередуй текст и графики, графики там, где цифры говорят сами.

**Графики** (рисует `components/research-blocks.tsx`, правила dataviz):

- `stats` — 2–4 крупные цифры-факта;
- `bars` — сравнение величин; `highlight: true` на строках, о которых история,
  остальные станут серыми (форма «emphasis»); до ~13 строк;
- `split` — доли целого, **2–3 части** (больше нельзя);
- `versus` — две величины на одной шкале (до/после, А против Б);
- `fact` — врезка «Кстати» с самым удивительным фактом;
- `quote` — цитата из исследования с автором.

У каждого графика — `title`, понятный `subtitle` (что за единицы) и `source`.
Никаких двух шкал на одном графике.

## 4. Опубликуй

```bash
npm ci
npm run research:cover <slug>   # превью через OpenAI
npx next build                   # должна пройти без ошибок
git add content/research public/research
git commit -m "research: <title>"
git push origin main
# подожди деплой: curl -s https://alex-friends.vercel.app/research/<slug> → 200
npm run research:publish        # пост в Telegram-канал
git add content/research && git commit -m "research: опубликовано в канал" && git push
```

Коммиты — с подписью `Co-Authored-By: Claude <noreply@anthropic.com>`.

Если что-то сломалось (нет ключа, бот не админ канала, сборка падает) — не
публикуй полуготовое: откати свои изменения и опиши проблему в итоговом ответе.
