# friends

Личное пространство Алексея Масюты — заметки и лонгриды про UX, коллекция пластинок и вишлист. Сайт-компаньон к [сайту-резюме](../alex).

**Стек:** Next.js 16 (App Router) · TypeScript · Tailwind CSS 4 · Framer Motion · next-themes. Тот же дизайн-фундамент, что и у резюме.

## Локально

```bash
npm install
npm run dev   # http://localhost:3000
npm run build # production-сборка
```

## Деплой

Push в `main` → автодеплой на Vercel.

После деплоя пропиши реальный адрес сайта-резюме в `lib/site.ts` (константа `RESUME_URL`) или через переменную окружения `NEXT_PUBLIC_RESUME_URL` в настройках Vercel.

## Утренняя газета

Весь цикл запускается в `.github/workflows/research.yml`: подготовка текста →
сборка → картинки и обложка → коммит → ожидание Vercel → Telegram.
Отдельное расписание Claude больше не требуется.

- Пн–пт: одна статья за московский день; суббота: дайджест пн–пт;
  воскресенье: без новых материалов. Правила текста — `content/research/AGENT.md`.
- Запуск в 08:05 МСК и повторные попытки по часовому расписанию. GitHub может
  задерживать cron; публикация в 08:00 ровно не гарантируется. До 08:00
  генерация отключена: Next.js исключает будущие статьи из статической сборки.
- Нужен секрет GitHub Actions `OPENAI_API_KEY` с доступом к Responses API,
  веб-поиску и модели `gpt-5.4`. API оплачивается отдельно от подписки ChatGPT.
  Модель можно изменить переменной репозитория `RESEARCH_MODEL` на совместимую
  с веб-поиском и Structured Outputs.
- Секреты обложек и Telegram остаются прежними. Если ключа OpenAI пока нет,
  workflow выдаёт предупреждение и продолжает обработку готовых материалов.
- Ручной запуск: Actions → Research publish → Run workflow → `generate=true`.
  Существующий выпуск того же дня не перезаписывается. `refresh` по-прежнему
  обновляет обложку и пост без подготовки новой статьи.

Проверки без API: `npm run research:test` и `npm run research:generate -- --check`.
`npm run research:generate -- --dry-run` **вызывает платный API**, но печатает
результат вместо записи файла. Обычно запускать генерацию следует в GitHub:
локальная команда сама ничего не отправляет в GitHub или Telegram.

Генератор ищет первоисточник и редактирует текст отдельным запросом. Перед
сохранением проверяет схему, наличие источника в результатах поиска, повторы,
темы, объём, цитаты и графики. Эти проверки не заменяют проверку фактов человеком.

## Структура

- `app/` — App Router: главная (`page.tsx`), `notes/` (заметки), `vinyl/` (пластинки)
- `components/` — `site-header`, `site-footer` (перелинковка с резюме), тема
- `lib/site.ts` — внешние ссылки и перелинковка
- `lib/utils.ts` — `cn()` helper
